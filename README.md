# LIFE COMPASS

iPhone向けの個人用PWA（ホーム画面に追加できるWebアプリ）です。

## 内容
- 朝・昼・夜のチェックリスト
- 人生の十訓と問題別の対策
- 問題記録・夜の振り返り日記
- 週間・月間の簡易分析
- JSONバックアップ／復元
- リマインダー設定画面

## iPhoneで使う方法
1. このフォルダの内容をHTTPS対応のWebホスティングにアップロードします。
2. iPhoneのSafariで公開URLを開きます。
3. 共有ボタン →「ホーム画面に追加」→「Webアプリとして開く」を有効にして追加します。
4. 記録は基本的にその端末・ブラウザ内に保存されます。設定画面から定期的にJSONバックアップを保存してください。

## 注意
- このパッケージはApp Store配布用のネイティブiOSアプリではなく、ホーム画面に追加して使うPWAです。
- 通知はアプリを開いている間に指定時刻を検知して表示します。アプリを閉じている間やバックグラウンドでは、指定時刻どおりの通知は保証されません。確実な通知にはiOSのリマインダーやショートカットとの併用を推奨します。
- 端末内保存のため、ブラウザデータ消去・端末故障に備えてバックアップしてください。
- 初期版は一人で使う想定で、アカウント同期やクラウド保存はありません。
- 宗教・哲学の倫理的な共通要素を日常行動に翻訳したツールであり、各宗教の教義全体を代表するものではありません。

## 将来の商用化に向けた技術的課題と改善提案（未実装）

このアプリは現在、個人利用版の完成を最優先としています。現段階では、外部決済・会員登録・広告・課金機能・AI連携はいずれも実装していません。将来像は「一般の人が簡単に使える自己管理アプリ」と「自己理解・倫理・人生観を深く掘り下げる独自サービス」の両立であり、以下の記録は、その将来拡張を妨げないための技術メモです。

### 設計方針
- 基本機能と将来の有料機能を分離できる構造にする
- 個人の日記・記録は、本人のデータとして扱う
- データ保存とAI連携を、将来分離できる構造にする
- AI連携を行う場合は、ユーザーの明示的な同意を必須とする（既定では外部送信しない現行方針を維持）
- 無料版でも、基本的な自己点検が完結する設計にする
- 将来の有料版では、AI自己対話・長期分析・月次レポートなどを追加できるようにする

### 現在の構成（事実）
- 画面・ロジック・スタイルは単一の `index.html` に集約されている
- データは端末内の `localStorage`（キー `lifeCompass_v1`）に1つのJSONオブジェクトとして保存される
- バックアップはJSONの書き出し／復元。書き出しデータには形式のバージョン番号が含まれていない
- 削除は「すべての記録を消去」のみで、記録単位の削除はできない
- Service Workerのキャッシュ版数（`life-compass-v1`）は手動で管理している
- 通知はアプリを開いている間のみで、バックグラウンド通知は行わない（PWAの制約）

### 技術的課題
1. データ形式の版管理：将来の機能追加時に、過去のバックアップを壊さず移行できるよう、書き出しJSONへのバージョン付与と移行手順が必要
2. 構造の分離：単一ファイル構成のままでは、基本／有料機能の分離、保存層とAI連携層の分離が難しい
3. 同意と送信範囲：AI連携を将来追加する場合、送信するデータの最小化、同意の取得・撤回、AIオフ（端末内のみ）モードの維持を設計する必要がある
4. データの権利：記録単位の削除、完全な書き出し（ポータビリティ）、アカウントなしでも使える現行方式との両立
5. 複数端末・同期：商用化時に同期を求められた場合、端末内保存の原則と両立する方式（例：任意参加・暗号化）の検討が必要
6. PWAの制約：バックグラウンド通知、保存領域の消去リスク、iOS固有の制約を、一般向けにどう案内・補完するか
7. 品質保証：現状は手動確認のみで、自動テストがない

### 改善提案（将来の検討順）
1. 書き出しJSONに形式バージョンを追加し、復元時に移行できるようにする
2. 保存処理を1か所に集約したまま、機能単位でコードを分割できる形へ段階的に整理する
3. 記録単位の削除と、月単位の振り返り・長期分析の強化（思考・行動・価値観の変化を追えるようにする）
4. AI連携は最後に、明示的同意と送信範囲の明示を前提として別途設計する（決済・会員登録・広告も同様に別フェーズとし、着手前に方針と影響を確認する）
